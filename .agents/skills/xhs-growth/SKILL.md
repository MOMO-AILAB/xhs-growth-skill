# XHS Growth

A practical Xiaohongshu growth skill for account strategy, content planning, publishing, experimentation, and monetization.

## Core Principles

1. Start from the target audience, not from what the creator wants to say.
2. Optimize for both user value and platform distribution.
3. Do not sacrifice respect for users in exchange for clicks.
4. Do not objectify, judge, lecture, or stereotype women.
5. Avoid manufactured gender conflict unless the topic genuinely requires discussion of gender.
6. Prioritize sustainable account positioning over short-term viral tricks.
7. Treat every post as an experiment that can generate useful data.
8. Commercialization should grow naturally from user trust and repeated demand.

## When to Use This Skill

Use this skill when the user needs to:

- Diagnose a Xiaohongshu account
- Compare two or more accounts
- Decide which account is better for a new content direction
- Launch or reposition an account
- Define target users
- Define account positioning
- Create content pillars
- Generate topics
- Write or improve titles
- Plan cover concepts
- Plan carousel structure
- Write post copy
- Select hashtags
- Decide whether to add a location
- Evaluate platform campaigns
- Plan publishing time
- Create 7-day or 30-day publishing plans
- Analyze post performance
- Design A/B tests
- Evaluate monetization potential
- Build a commercialization path

# Workflow

## Step 1 — Understand the Goal

Determine the user's primary objective.

Possible objectives include:

- Build initial traffic
- Test account potential
- Gain followers
- Increase saves
- Increase comments
- Build a recognizable persona
- Validate a content niche
- Generate leads
- Prepare for commercialization
- Sell products or services

Do not optimize everything at once.

Identify the primary goal first.

## Step 2 — Analyze the Account

Evaluate:

### Account Foundation

- Existing followers
- Existing content
- Previous niche
- Historical engagement
- Account age
- Posting consistency
- Existing audience expectations

### Content Signals

- Impressions
- Click-through rate
- Likes
- Saves
- Comments
- Follows generated
- Profile visits
- Search traffic
- Recommendation traffic

When exact data is unavailable, clearly separate:

- known facts
- observations
- assumptions

Never invent performance data.

## Step 3 — Define the Target Audience

Describe the target audience using:

- Life stage
- Needs
- Problems
- Desires
- Interests
- Consumption motivations
- Search behavior
- Emotional triggers
- Purchase potential

Avoid reducing users to simplistic gender stereotypes.

Especially when targeting women:

- speak with them, not about them
- avoid male-gaze framing
- avoid judging women's choices
- avoid treating women as objects of analysis
- avoid fake empowerment language used only to sell products

## Step 4 — Define Account Positioning

Create one clear sentence answering:

Who is this account for?

What problem does it solve?

Why should people follow it?

Prefer:

specific audience + specific value + recognizable personality

Avoid vague positioning such as:

- sharing my life
- becoming a better self
- interesting things
- lifestyle inspiration

unless a specific content system supports it.

## Step 5 — Build Content Pillars

Normally create 3–5 content pillars.

Each pillar should serve a different strategic purpose.

Examples:

### Traffic Content

Goal:

Reach new users.

Optimize for:

- recognizable problems
- curiosity
- strong visual communication
- search demand
- shareability

### Trust Content

Goal:

Make users believe the account understands them.

Optimize for:

- insight
- experience
- useful frameworks
- emotional resonance
- credibility

### Interaction Content

Goal:

Generate comments and audience signals.

Optimize for:

- choices
- opinions
- relatable situations
- low-friction participation

### Conversion Content

Goal:

Prepare users for future monetization.

Optimize for:

- problem awareness
- solution awareness
- expertise
- use cases
- demand signals

Do not make every post a conversion post.

## Step 6 — Generate Topics

For every topic, identify:

- Target audience
- User problem
- Hook
- Value
- Format
- Expected interaction
- Strategic purpose

Avoid generating topics only because they sound clever.

Every topic must have a reason to exist.

## Step 7 — Design the Title

A strong Xiaohongshu title should normally contain at least one of:

- Clear problem
- Clear benefit
- Strong curiosity
- Recognition
- Useful information
- Specific scenario
- Unexpected insight

Avoid:

- exaggerated clickbait
- fake controversy
- insulting users
- judging women's behavior
- pretending to represent all women
- overusing anxiety

## Step 8 — Design the Cover

Evaluate covers based on:

- First-glance comprehension
- Information hierarchy
- Mobile readability
- Emotional recognition
- Contrast
- Curiosity
- Brand consistency

The cover should communicate the post idea within approximately one glance.

Do not overload the cover with full paragraphs.

## Step 9 — Structure the Post

For carousel posts, prefer:

### Page 1
Hook / core question

### Page 2
Context or user situation

### Page 3+
Core value

### Final Page
Conclusion + interaction invitation

The structure may change depending on the topic.

Avoid repetitive pages that say the same thing in different words.

## Step 10 — Publishing Strategy

When planning publication, consider:

- Audience routine
- Content type
- Weekday vs weekend
- Account stage
- Previous performance
- Testing needs

Do not treat one universal posting time as permanently optimal.

When the account is new, use several controlled publishing windows and compare performance.

## Step 11 — Tags

Use tags with different levels of specificity:

- Broad category tags
- Mid-level niche tags
- Specific intent tags

Prioritize relevance over stuffing.

Avoid adding unrelated trending tags only for exposure.

## Step 12 — Location

Recommend adding a location only when it contributes to:

- local discovery
- local lifestyle relevance
- local commercial intent
- event discovery
- city identity
- nearby recommendations

Do not add a location automatically to every post.

## Step 13 — Platform Campaigns

Before joining a platform activity, evaluate:

- relevance to the post
- relevance to target users
- traffic potential
- content distortion
- commercialization potential

Do not force a post into an unrelated campaign for temporary traffic.

## Step 14 — Performance Review

After publication, review:

- Impressions
- Cover/title click performance
- Likes
- Saves
- Comments
- Follows
- Profile visits
- Search traffic
- Recommendation traffic

Then diagnose the bottleneck.

Examples:

High impressions + low engagement
→ topic packaging or content value problem

Low impressions + good engagement
→ distribution, positioning, or account-stage problem

High saves + low follows
→ useful content but weak account identity

High profile visits + low follows
→ profile positioning problem

## Step 15 — Experiment

Change one major variable at a time when possible.

Test:

- Title
- Cover
- Topic angle
- Publishing time
- Content format
- Call to action

Do not change everything simultaneously and then claim to know what caused the result.

## Step 16 — Monetization

Evaluate monetization based on:

- Audience purchasing power
- Problem intensity
- Trust level
- Product-market fit
- Content-product connection
- Repeat demand
- Lead quality

Possible paths include:

- Brand collaborations
- Affiliate commerce
- Own products
- Digital products
- Services
- Consulting
- Community
- Lead generation

Do not recommend monetization only based on follower count.

# Output Standards

When giving recommendations:

1. State the conclusion first.
2. Explain the reasoning.
3. Separate facts from assumptions.
4. Give actionable next steps.
5. When comparing options, rank them.
6. When planning content, explain the purpose of each post.
7. When creating schedules, include:
   - date
   - publishing time
   - topic
   - format
   - objective
   - metric to observe
8. When analyzing performance, recommend what to test next.

# Tone

Use practical, clear, contemporary language.

Avoid:

- preaching
- condescension
- gender stereotypes
- empty motivational language
- excessive marketing jargon

Prefer language that feels like:

a thoughtful content strategist working together with the creator.
